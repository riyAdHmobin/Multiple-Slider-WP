== Description ==

Make your WordPress website fully accessible and WCAG-compliant in minutes.  
**Screen Reader Accessibility** adds essential tools such as text-to-speech, high contrast modes, dark mode, dyslexic fonts, enlarged cursor, reading guides, zoom, ARIA fixes, and AI-powered accessibility improvements using ChatGPT.

It helps fix the most common accessibility issues automatically (missing ALT text, incorrect heading order, low contrast, missing labels and ARIA roles), improving compliance and usability for visually impaired users.

The plugin helps visually impaired users navigate your website with ease, **meets accessibility regulations (WCAG / ADA)**, and improves overall user experience for everyone.

== Installation ==

1. Upload and activate the plugin.  
2. A fixed accessibility toolbar will appear on the frontend.  
3. Configure additional options in **Settings → Screen Reader Accessibility**.  
4. If upgrading to PRO, uninstall the FREE version before installation.  

For the PRO installer, go to:  
**Plugins → Add New → Upload Plugin → Choose File → Install Now**

== Frequently Asked Questions ==

= Is Screen Reader Accessibility WCAG compliant? =
Yes. The plugin includes many tools required for WCAG/ADA compliance, such as text-to-speech, contrast modes, font adjustments, ARIA roles, headings fixes and more.

= Does the plugin support text-to-speech in multiple languages? =
Yes. Over 50 languages are supported and PRO users gain access to advanced audio engines.

= Will Screen Reader Accessibility work with Elementor, Divi, Gutenberg and any theme? =
Yes. It is fully theme-independent and works with any builder.

= What does the AI (ChatGPT) integration do? =
It analyzes your site and automatically fixes accessibility problems such as missing alt text, poor contrast, wrong heading order, and missing labels.

= Can this plugin help visually impaired users navigate my site? =
Absolutely. That's the main purpose — to improve accessibility and usability for visually impaired visitors.

= Is the plugin lightweight? =
Yes. The core plugin is optimized and loads minimal resources.
